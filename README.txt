DESI DASTARKHWAN WEBSITE
========================

This project expands the original Lab 11 Desi Dastarkhwan page into a small
three-page website while keeping its original maroon, cream and brown colour
scheme, Arial font, food theme, menu items and prices.

FILES
-----
index.html       Home page
menu.html        Full menu page with a small selection interaction
about.html       About and sample contact information
style.css        Shared styles used by all three pages
script.js        Menu selection interaction
images/biryani.jpg  Image supplied with the assignment

HOW TO OPEN
-----------
1. Extract the ZIP file.
2. Keep the three HTML files, style.css, script.js and images folder together.
3. Double-click index.html to open the website in a browser.
4. Use the navigation links to move between pages.

GIT COMMIT SUGGESTIONS
----------------------
Run these commands in the project folder. They are examples of meaningful
progress commits; make each commit after the corresponding work is complete.

git init
git add index.html style.css images/biryani.jpg
git commit -m "Set up the original Desi Dastarkhwan home page"

git add menu.html
git commit -m "Add a separate menu page with dish prices"

git add about.html
git commit -m "Create an about page and sample contact section"

git add style.css
git commit -m "Apply consistent responsive styling across all pages"

git add script.js README.txt
git commit -m "Add menu selection interaction and project instructions"

NOTE
----
The contact information is sample content for the student project. The menu
selection is a front-end demonstration only; it does not submit a real order.
Review the pages, test the links and interactions, and adjust any details your
instructor wants before submitting.
